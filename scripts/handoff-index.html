Making it yours

  1. Serve the folder — npx serve .. The pages link to each other by path, so they need a server rather than the file system.
  2. To deploy it: make a Firebase project, put its id in .firebaserc, and fill in every PASTE_YOUR_… in the HTML.
  3. Swap https://YOUR-DOMAIN.com in the canonical and og:url tags for your own.
  4. Push the database rules and the site with firebase deploy.

Until step 2: every page reads and renders correctly, but the three forms cannot save. They fail with a readable message rather than an error, and the crew sheet drops into a local preview mode.

Full detail — including which data node is readable by whom, and how to light up the live map and board — is in README.md next to this file.
